KIẾN TRÚC CLIENT / SERVER TRÊN NỀN HTTP/1.1

Trang này dùng để minh họa điều hướng đa trang, cập nhật bảng History (SQLite) và nút Back / Forward / Refresh trên Java Swing Browser.

  • Server: Lắng nghe TCP port mặc định 8080, phục vụ tệp tĩnh từ thư mục www/ và API /api/submit.
  • Client: Dùng java.net.http.HttpClient gửi request HTTP thực thụ và hiển thị Status Code + Response Headers.
