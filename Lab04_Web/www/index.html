LAB 04 — JAVA HTTP WEB SERVER & BROWSER

Chào mừng bạn đến với máy chủ HTTP được xây dựng bằng Java HttpServer (com.sun.net.httpserver.HttpServer). Hãy nhấn vào các liên kết bên dưới hoặc dùng các nút GET / HEAD / POST trên trình duyệt Swing để kiểm thử.

Danh mục dịch vụ trên Web Server (Thư mục www/)

Tài nguyên Đường dẫn (URL Path) MIME Content-Type Chức năng kiểm thử
Trang giới thiệu phụ /about.html text/html; charset=utf-8 Kiểm tra điều hướng link, nút Back / Forward
Dịch vụ PDF /tailieu.pdf application/pdf Xem trang PDF trực tiếp bằng PDFBox & Download file
Dịch vụ MP3 /nhac.mp3 audio/mpeg Nghe nhạc MP3 trực tiếp từ HTTP URL & Download
Dịch vụ MP4 /video.mp4 video/mp4 Xem video MP4 (H.264/AAC) hỗ trợ HTTP Range & Download
API nhận HTTP POST /api/submit application/json; charset=utf-8 Nhấn nút POST để gửi dữ liệu form/JSON lên Server

Hướng dẫn quan sát HTTP Header khi bảo vệ

  • GET: Trình duyệt nhận đủ Status Code (200 OK), Response Headers và toàn bộ Body.
  • HEAD: Server chỉ trả Status Code và Headers (kèm Content-Length), Body thực tế rỗng 0 bytes.
  • POST: Trình duyệt gửi chuỗi dữ liệu ở ô POST Body tới /api/submit và nhận phản hồi từ Server.
